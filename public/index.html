03 / 龙分模型

分数不是推荐，只是把证据摆平

方向分由八个可解释因子加权得出，风险扣分与置信度单独输出。看懂下面四条读法，就不需要信任何人。

因子权重

因子权重衡量什么 / 满分条件

四维体检

龙分只回答「量价结构健不健康」，回答不了「合约能不能碰、筹码在谁手里、现在该不该进」。 这四个问题由体检补上：在任意卡片或龙虎榜展开行点「四维体检」按需触发，结果缓存 6 小时。 安全维度是一票否决——命中硬红线直接放弃，不参与加权，避免「合约随时能跑路但量价很漂亮」得出高分。

维度问的问题看什么 / 什么情况直接放弃
安全 合约能不能碰 蜜罐、禁止买入、不能全额卖出、买卖税超 10%、不可转让、冻结或销毁权限未放弃、创建者有蜜罐前科 —— 任一条命中直接放弃；未开源、代理合约、可增发、LP 锁定不足按扣分处理。所有者已放弃所有权时，owner 类风险实际不可触发，会降级并标注。
叙事 故事还传不传得动 参与广度（近 1 小时成交笔数 ÷ 日均）、瞬时加速度、传播载体（官网 / X / Telegram / Discord / 推广位 / 代币资料 / 持币地址数）、持币地址增量。阶段分萌芽期 / 传播期 / 常态 / 高潮期 / 退潮期。故事内容本身无法从公开接口获得，必须人工判断，报告里会明确写出这一点。
筹码 筹码在谁手里 前十大、第一名单个、DEV / owner 自留、持币地址数、前十大潜在抛压与池子深度的比值、捆绑地址网络。集中度会剔除池子储备、销毁地址与已锁仓地址后重算。风险等于集中度 × 退出通道宽窄：人数少且池子是唯一出口才致命，大市值标的前十大高不等于致命。
位置 该不该进、进多少 市值分档、叙事阶段、退出通道，据此给结论与仓位。仓位由风险预算倒推：单笔可承受亏损 ÷ 阶段止损距离，再取「风险预算 / 流动性上限 / 单币上限」三者最小值，乘四维质量系数与阶段系数。同时给出分批计划与四条离场条件。
综合分 ＝ 安全 ×0.40 ＋ 筹码 ×0.30 ＋ 叙事 ×0.30 位置不参与加权，它是执行环节 缺数据不给中性分：拿不到合约数据按最高风险处理 数据源：GoPlus / honeypot.is / RugCheck / DexScreener 同名检索

仓位是风险口径下的「可承受上限」，不是建议下单金额，也不代表本工具认为该买。真正要不要开仓， 取决于你自己的判断与承受能力。

04 / 抓龙胜率

先记录，后结算 —— 这一页不做历史回放

龙分的八个因子里，只有量能爆发、价格加速度、池龄、市值这几项能从公开历史数据里重建； 买卖笔数分布、池子深度、持币地址数、社交与付费推广状态，公开历史里根本不存在。 拿现在的值去回放过去，等于把「后来涨了才会变大的成交量」当成入场时的依据 —— 那不是回测，是把答案抄进题目。所以这里换一种做法：每个标的第一次出现在榜单上时， 把那一刻的真实状态（分数、八因子、市值、深度、池龄）与价格原样记下来； 等 15 分钟 / 1 小时 / 6 小时 / 24 小时候，再用那一刻的真实价格结算。 信号是先记的，价格是后取的，没有前视偏差。

这一页默认回答的是一个明确的策略问题：只买真龙、翻倍（+100%）就止盈，到底赚不赚钱。 三条信号腿（真龙 / 档位升级 / 首现）共享同一套出场规则，所以切换口径时看到的差别， 只来自入场门槛这一个变量。真龙这条腿自 v3 起才开始记录，不回溯补历史 —— 补历史就等于把后来的价格当成入场依据。

视界
信号

「只买真龙」＝入场门槛就是真龙档，不加任何附加条件，这是本页默认口径。 「档位升级信号」＝首次达到龙头候选及以上；「首现信号」＝标的第一次进入榜单，代表闭着眼睛买。 三条腿的出场规则完全相同（翻倍 +100% 止盈，不设止损，其余持满视界）， 所以两种口径的差别只来自入场门槛 —— 否则看到的差异里混着出场规则的贡献，比不出来。 账本需要时间积累：15 分钟视界几分钟就能出数，24 小时视界要等一天；真龙档很稀有，真龙口径的样本积得最慢。

怎么读这些数

指标它回答什么 / 为什么不能单独看
出场规则 在各自视界窗口内触及 +100%（翻倍） 即以那一笔成交（记为止盈），没触到就持满视界，不设止损。 成交按止盈线价计，不按跳空后看到的那口价 —— 挂在线上的限价单就是线价成交，真实成交只会更好，所以报出来的是保守下界。三条腿用同一套出场规则，两种口径的差别才只来自入场门槛。
止盈线是标定出来的，不是拍的：这个市场的收益极度右偏（中位 0%、均值全靠个位数的大赢家撑着），所以不能用胜率挑线。把每个已结算样本的收益按各条候选止盈线封顶重算，10% 截尾均值在不止盈时是 −6.0%，+30% 掉到 −6.4%，+15% 掉到 −7.5%，到 +50% 及以上才回到 −6.0%。结论是止盈线要么不设，要么设得足够高：+40% 及以下都在削真金白银。取 +100% 是取「只对真正罕见的翻倍事件生效」这一点。
这个封顶算法不是糊弄：任何结算在止盈线之上的样本，价格既然收在线之上，途中必然穿过这条线，止盈就按线成交 —— 对这半边样本，封顶是精确重演；只有结算在线下的样本才可能被低估。所以这条线的成本被量到，收益只会被低估。
止损被否掉的理由不是「数字全变差」——实测是混合的：止损削掉了左尾（均值 −9.1% → −5.1%），但胜率略降（22.3% → 20.9%）、中位收益没改善（−1.1% → −1.4%）、中位超额反而更差（−3.9% → −4.6%）。决定性的是结构原因：止损只能落在「有观测点」的时刻上，而真正该止损的那批（池子被撤、标的归零）往往先掉出候选池、不再产生观测点，止损根本不会响，它响的是「还在、只是波动大」的那批。
上面这些数是持续前瞻累积的账本快照（2026-09-26 01:29，238 个已结算样本），样本长大一轮数字就会小幅漂；结论比数字稳——截尾均值的交叉点一直在 +40% 与 +50% 之间。
代价说清楚：止盈把上行封在 +100%，因此「最好」不会超过止盈线、「翻倍以上」与「止盈触发」是同一批样本 —— 这是止盈的代价本身，不是缺陷。
胜率 正收益占比。单看它没有意义 —— 如果那段时间全市场都在涨，闭着眼睛买也是高胜率。所以它永远和下面两项绑在一起。
榜单指数基准 同一时段、同一个榜单里所有连续在榜标的的等权收益（每轮再平衡，单轮做 10% 截尾）连乘成一条参考线。「信号收益 − 同期指数收益」＝中位超额，这才回答「雷达选的比雷达池子的平均强吗」。
这里刻意不用中位数：这类新池子里有大量「一分钟内价格完全没动」的标的，只要过半没动，当轮中位数就精确等于 0，整条线会永远贴在 1.0000，基准恒为 0 之后「跑赢基准」就退化成「收益为正」，和胜率成了同一个数。中位口径仍然记录，只作参照。
样本流失率 到点却补不到价格的信号。掉出榜单的标的很可能就是归零那批，把它们从分母里抹掉会让胜率系统性虚高，所以单独计数、单独显示。
最大浮亏 从开仓到结算之间出现过的最差浮亏。只有收益没有回撤，胜率会显得比实际舒服得多 —— 赚 50% 的前提是你先扛住了 −60%。
档位分层 真龙 / 龙头候选 / 潜龙 / 观察 / 别碰 各自的表现。如果档位越高中位收益反而越低，说明龙分在这段样本上没有区分度 —— 这比胜率本身更值得看。
结算价必须为正：价格 ≤ 0 一律拒绝结算，避免把「池子没了」记成 0 收益 缺基准时超额写「无采样点」，绝不用 0 冒充「与市场持平」 样本不足 30 笔只报计数，不给胜率 48 小时仍补不到价格记流失，不并入胜率 开仓后按 5 分钟一个窗口记录观测价，最大浮亏与掉榜回补都靠它 止盈优先于视界：窗口内触线就以那一笔成交，成交时点记触线那一刻 止盈按止盈线价成交：线上规则不会跑赢自己设的上限 真龙腿从 v3 起记录，不回溯补历史

已知偏差，不藏：候选池由推广榜 / 新资料 / 关键词扩样合成，不是全市场，所以这份统计只说明「在这个池子里信号值不值」， 不能外推到整个市场。榜单指数偏向活得久的标的 —— 而且这一条比原先以为的更严重：观测点只在标的还留在候选池里时 才产生，而候选池取自「最新推广 / 最新资料」，涨得最猛的那批恰好最快离开候选池（实测留在池里的那批 1 小时收益 中位 −0.1%，离开池里被回补结算的那批中位 +13.6%）。榜单指数只由「上一轮与这一轮都在榜」的标的构成， 因此它系统性偏低，超额收益因此偏乐观。这是已知缺陷，尚未修复。 候选池不是全市场、结算价是公开报价而非可成交价，这两条同样成立。 另外，本地 Node 形态常驻运行时采集是连续的；纯静态部署只在页面打开时采集，关掉的时段没有观测点， 到期补不到价格的信号会计入流失而不是被当成中性。数据只存在本机，不上传。

边界与缺口

这些事，这一页做不到

  • 只查得到接口里有的字段。DexScreener 没收录的链或代币不会出现在候选池，不等于安全，也不等于危险。
  • 候选池由「官方推广榜 + 最新代币资料 + 关键词滚动扩样 + 你的自选 + 上轮强势标的」合成，每轮覆盖 100～160 个，不是全市场。
  • 数据是每次扫描的链上快照，不是实时推送。限流或上游异常时页面会直说，不会用缓存或演示数据撑场面。
  • 四维体检按需触发，不对全池逐轮执行：GoPlus 免费档一次只受理一个地址，RugCheck 的全量报告单币可达数 MB。结果缓存 6 小时，点击时若不是最新请重跑。
  • 体检里的叙事维度只能给出传播载体与强度，故事讲了什么、能不能被复述与二次创作，机器读不出来，必须人工判断。报告里不会用猜测冒充结论。
  • 筹码数据来自第三方风控接口，对「LP 由合约托管」等情形常有误记，关键标的仍建议在链上自行复核。缺数据时不判绿，也不谎称发现了问题。
  • 仓位是风险预算倒推出来的可承受上限，不是建议下单金额。本工具不给买卖点，也不判断你会不会赚钱。
  • 不连接钱包、不需要任何密钥、不发起交易。你的地址和私钥都不会出现在这一页。
  • 「可看」的意思是「值得自己去核一遍」，不是「可以买」。真正的风险永远在合约之外。
  • 抓龙胜率页报的是「先记录、后结算」的前瞻样本，不是历史回放。它刚上线时样本是空的，要跑够时间才有数字；样本不足 30 笔时页面只报计数，不给胜率。
  • 胜率必须与「同期榜单指数基准」和「样本流失率」一起读。单独看胜率，在普涨行情里会高得毫无意义；把归零掉出榜单的标的漏掉，胜率还会更高。
  • 账本只统计本工具候选池里的标的，不是全市场。它回答「在这个池子里信号值不值」，不能外推到整个市场。
